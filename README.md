# Napo Pizzería: App del Repartidor

PWA para la parte del repartidor de Napo Pizzería. Permite ver pedidos, consultar la ubicación de entrega y revisar reseñas, con inicio de sesión con Google.

 **Demo en línea:** [URL de tu Firebase Hosting]

## Funciones

- Inicio de sesión con Google
- Lista de pedidos asignados
- Ubicación de entrega
- Reseñas
- Instalable como app (PWA)
- Modo oscuro minimalista

## Tecnologías

- HTML, CSS y JavaScript
- Firebase Authentication (Google)
- Cloud Firestore
- Firebase Hosting
